# 1.0.0

首个社区定制版源码发布，Git 标签 `custom-v1.0.0`。基于 Teable 增加钉钉组织目录及社区版权限矩阵。

## 首版功能

- 钉钉企业连接后台配置、加密凭据、部门与员工目录同步、预览与同步变更确认。
- 本地账号绑定、业务角色映射、表级权限矩阵与权限来源预览。
- 字段隐藏和只读、按本人或同企业直接部门创建者限定记录范围。
- HTTP、批量记录和实时消息的授权边界，以及解绑、离职和撤权后的访问限制。
- 受限账号的个人筛选、排序、分组、搜索，以及配套计数、分组点和记录位置查询。
- 单机部署配置、HTTPS/WebSocket 代理示例、密钥生成及备份恢复操作说明。

## 首版验证

- 后端受影响测试：464 项通过，20 项按既有环境条件跳过。
- 管理界面测试：19 项通过；SDK 实时连接及错误处理：7 项通过。
- 真实本地接口：v1 91 项通过；v2 加 Chrome 104 项通过。
- 前后端完整类型检查通过；测试夹具已清理，本地服务健康。
- 公开副本完成凭据、账号及企业信息脱敏检查，已关闭 Fork 继承的 Actions，避免触发上游镜像发布流程；本次使用本地验收和 GitHub CLI 发布。

历史需求、设计及验证记录见[知识库](../knowledge-base/organization-permissions/README.md)，部署方法见[部署说明](../../deploy/organization-community/README.md)。

## 交付范围和使用限制

本次发布源码，GitHub 提供该标签的源码归档。尚未发布预构建生产容器镜像；生产服务器部署、TLS/WebSocket 环境验收、真实备份恢复及容量测试继续单独执行。可以按部署说明使用 `VERSION=1.0.0` 自行构建定制镜像。

首次上线须完成账号绑定、资源成员和权限策略配置。受限表的导出、SQL、通用聚合、跨表写入及未审查批量入口仍不可用；后台内部任务及插件全路径尚未完成生产认证。

迁移已有数据库时，须同时迁移附件和实际加密密钥配置，并先备份。不要使用新实例随机密钥覆盖已有密文对应的密钥，不通过回退旧镜像假设数据库迁移可逆。
