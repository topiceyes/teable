# 1.1.0 — 企业钉钉扫码登录

- 登录页增加按企业展示的钉钉扫码登录入口。
- 后台“钉钉组织目录 → 编辑企业配置”可单独启用登录和首次扫码开户，升级默认关闭。
- 已绑定员工直接登录原账号；允许开户时自动创建普通账号并绑定有效员工。
- 已有同邮箱账号需先登录原账号，再在“个人设置 → 账户”扫码绑定，避免错误合并。
- 浏览器凭证、10 分钟一次性 state、配置版本检查和企业身份二次核验保护回调；拒绝外部人员、停用账号和冲突绑定。
- 新账号不自动成为管理员、空间或数据库成员，现有组织权限矩阵保持生效。
- 修复生产打包混用模块导致的 v2 DI token 不一致，补充容器迁移目录路径，以 UID 1001 运行并降低构建并发。

启用前在企业内部应用的“钉钉登录与分享”配置系统显示的完整回调地址，并授权 Contact.User.Read。自动化测试覆盖身份适配器、真实 PostgreSQL 事务、HTTP、浏览器页面和已有权限；实际扫码授权需要企业管理员及用户完成，测试不能代替平台授权。
