# 本地开发知识库

此目录用于保存每期需求、设计决策、实现范围和验证记录。当前仓库没有发现既有知识库路径，因此采用仓库内 `doc/knowledge-base`，便于版本管理和后续检索。

## 归档约定

每期完成时必须新增或更新一期记录，包含：需求与验收目标、设计及权限边界、实现文件入口、实际验证结果、尚未实现内容、迁移及部署说明。代码已实现、测试已验证、已部署及真实联调四种状态分别记录，不能互相替代。
