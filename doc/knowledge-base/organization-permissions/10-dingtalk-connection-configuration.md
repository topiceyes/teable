# 第 10 期：后台配置钉钉企业连接

日期：2026-11-09（Asia/Shanghai）。

## 需求与入口

用户在部署后发现组织目录没有可填写企业凭据的入口，要求在后台完成钉钉配置。

入口：系统管理 → 钉钉组织目录（`/admin/directory`）→ **配置钉钉企业**。

本期提供新建企业连接、编辑数据库连接、使用未保存的表单测试连接。保存后立即进入原有部门、员工、业务角色和同步日志页面。部门、员工仍来源于钉钉同步；本期没有增加手动创建部门、钉钉扫码登录或自动定时同步。

## 页面行为

- 字段为企业名称、CorpId、AppKey / ClientId、AppSecret / ClientSecret。
- 新建连接须填写 AppSecret。CorpId 保存后不可编辑，其他企业需新建连接，避免已有员工、角色和矩阵关联被误移到另一企业。
- 编辑已有连接时 AppSecret 始终为空，留空保留原密钥；修改 AppKey 必须填写配套的新密钥。
- 密钥输入使用密码框，不写入浏览器持久化存储。提交期间禁用重复操作；修改表单后清除此前连接测试的成功提示。
- 测试连接不会保存配置，也不会启动通讯录同步。凭证有效、能够读取根部门后显示返回的根部门名称，由管理员核对目标企业。
- 测试只覆盖取 token 和根部门读取。不能据此断言 CorpId 与应用已经由服务端交叉核验，亦不能断言员工、角色读取权限或通讯录可见范围完整；仍须执行原有同步预览并检查变更。
- 环境变量 `BACKEND_DINGTALK_DIRECTORY_CONNECTIONS` 继续有效。页面将此类连接标为服务器管理，仅显示公开元数据，编辑仍走部署配置。同 CorpId 的环境变量配置优先，后台不覆盖它。

## 存储与密钥

在既有 `directory_connection` 上新增：

| 字段                    | 用途                                         |
| ----------------------- | -------------------------------------------- |
| `app_key`               | 应用标识，可以回显给实例管理员               |
| `app_secret`            | AES-256-GCM 密文，仅服务端解密后调用钉钉     |
| `configuration_version` | 乐观并发版本；既有行初始为 0，成功保存后递增 |

迁移：`20261109030000_add_directory_credentials`。保留原有企业、部门、员工、绑定及角色 ID。

复用 `ThirdPartyCredentialCodec` 的 HKDF 密钥派生及旧密钥解密能力，但本功能强制加密写入，不受旧第三方凭证可选加密开关影响。拒绝使用公开的默认加密根密钥保存配置；解密失败返回通用错误，不把密文作为凭证继续请求。

加密根使用 `BACKEND_THIRD_PARTY_CREDENTIAL_ENCRYPTION_SECRET`，兼容已有 `SECRET_KEY` 回退。部署其他环境时须设置私有且稳定的根密钥，并随数据库备份妥善保管；更换根密钥需按现有 codec 的 `_OLD` 机制保留旧值，不能直接丢弃。

本机原先没有上述根密钥，已在被 Git 忽略的 `apps/nextjs-app/.env.development.local` 中生成专用随机值，文件权限为 0600。没有修改其他子系统的密钥，真实值不写入源码、归档或工具输出。

为兼容本机此前可能按旧默认根加密的第三方凭证，在 `_OLD` 中保留此前的默认根供解密使用；新目录凭证始终使用专用随机主密钥加密。

## 接口与权限

均要求实例管理员权限 `instance|update`。

| 方法 | 路径                                              | 行为                                                                          |
| ---- | ------------------------------------------------- | ----------------------------------------------------------------------------- |
| GET  | `/api/admin/organization/dingtalk/connections`    | 返回企业、AppKey、来源、密钥是否存在及配置版本；不返回密钥或密文              |
| POST | `/api/admin/organization/dingtalk/saveConnection` | 创建或编辑连接；body 为 corpId、name、appKey、可选 appSecret、expectedVersion |
| POST | `/api/admin/organization/dingtalk/testConnection` | 只读测试表单或保留的密钥，返回 connected 和 departmentName                    |

新建 expectedVersion 为 0，编辑使用页面读取的版本。重复 CorpId、旧版本、配置锁竞争和环境变量管理冲突返回 409；新建缺密钥、替换 AppKey 未提供密钥、提交密文或多余字段返回 400。上游错误只返回受控错误码，不透传请求 URL、响应体或凭证。日志脱敏字段新增 AppSecret；配置审计仅记录企业 ID、版本和是否更换密钥。

## 同步兼容与并发

新增连接服务统一解析环境变量与数据库凭据，现有同步预览和执行复用该服务。配置修改与同步提交共用企业 advisory lock；配置保存采用版本条件更新，避免覆盖其他管理员的修改。

同步预览 token 包含配置版本。更改配置后，旧预览无法直接执行；同步读取远程快照期间如果配置发生变化，提交时再次检查版本并拒绝写入。页面保存后重新读取连接列表，并按企业和版本重建同步面板，清除旧预览。
